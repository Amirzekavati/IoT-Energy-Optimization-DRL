# طرح پوستر پروژه

**عنوان:** بهینه‌سازی مصرف انرژی در IoT با Deep Reinforcement Learning (DQN)

## بلوک‌های پیشنهادی پوستر

### ۱) عنوان و مشخصات
- عنوان فارسی + انگلیسی
- نام دانشجو، استاد راهنما، دانشگاه / دانشکده

### ۲) مسئله و انگیزه
- محدودیت باتری نودهای حسگر
- رشد اتصالات IoT ([1])
- نیاز به تصمیم هوشمند ارسال / خواب

### ۳) اهداف
- شبیه‌سازی شبکه IoT
- آموزش DQN برای زمان‌بندی خواب/ارسال
- مقایسه با سیاست‌های پایه
- داشبورد Streamlit

### ۴) معماری سیستم
تصویر: `assets/architecture/high_level_architecture.png`

`UI → Simulation → RL (DQN) → Analytics`

### ۵) روش
- حالت نود: active / sleep / dead
- مشاهده: انرژی + وضعیت زنده + زمان
- عمل: sleep یا transmit برای هر نود
- پاداش: بسته بیشتر + عمر بیشتر − مصرف انرژی

### ۶) نتایج کلیدی
- جدول کوتاه مقایسه سیاست‌ها
- نمودار: `assets/charts/policy_comparison.png`
- نمودار: `assets/charts/energy_curves.png`

### ۷) نتیجه‌گیری
- DQN مصالحه‌ای بین تحویل داده و مصرف انرژی ایجاد می‌کند
- داشبورد امکان آزمایش تعاملی را فراهم می‌کند

### ۸) کارهای آینده
- Multi-agent RL، کانال واقعی، سخت‌افزار

## نکات طراحی
- حداکثر یک جمله برای هر بلوک
- فونت خوانا از فاصله ۱–۲ متر
- یک دیاگرام معماری + یک/دو نمودار نتیجه کافی است
