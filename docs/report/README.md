# گزارش پروژه

فایل‌های این پوشه اسکلت متن گزارش هستند تا در Word/LaTeX دانشگاه منتقل شوند.

## ترتیب پیشنهادی تکمیل

1. فصل ۱ — مقدمه (با ارجاع [1])
2. فصل ۲ — فقط تیترها آماده است؛ متن را بخش‌به‌بخش بنویسید
3. فصل ۳ — روش (براساس کد فعلی تقریباً کامل است)
4. فصل ۴ — نتایج را از داشبورد / نوت‌بوک ۰۶ پر کنید
5. فصل ۵ — جمع‌بندی
