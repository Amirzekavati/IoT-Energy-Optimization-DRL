# گزارش پروژه

فایل‌های این پوشه اسکلت متن گزارش هستند تا در Word/LaTeX دانشگاه منتقل شوند.

## ترتیب پیشنهادی تکمیل

1. فصل ۱ — متن تکمیل شد
2. فصل ۲ — متن تکمیل شد
3. فصل ۳ — روش (براساس کد فعلی)
4. فصل ۴ — نتایج آزمایش پر شد (۳ نود، ۸۰۰۰ گام آموزش)
5. فصل ۵ — نتیجه‌گیری به‌روز شد
