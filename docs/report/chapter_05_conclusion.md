# فصل ۵ — نتیجه‌گیری و کارهای آینده

## ۵-۱ خلاصه دستاوردها

- پیاده‌سازی شبیه‌ساز شبکه IoT با مدل انرژی
- تعریف محیط Gymnasium و تابع پاداش
- آموزش عامل DQN و مقایسه با سیاست‌های پایه
- داشبورد Streamlit برای اجرا، آموزش و ارزیابی

## ۵-۳ محدودیت‌ها
